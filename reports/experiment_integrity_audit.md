## Ready-to-paste methodology text

```
The merged corpus was split into train (1144 rows), validation (160 rows), and an untouched final test set (157 rows) using group-disjoint GroupShuffleSplit (random_state=42). Group keys are: essay_id for AAEC rows, topic_group for IBM ArgKP rows, and template_family for synthetic rows. Near-duplicate padding vignettes (0 rows) were isolated before splitting and excluded from all evaluation. The fusion weight alpha was selected by macro-F1 sweep on the validation set only. The temperature calibration parameter T was fitted by NLL minimisation on the validation set only. The final test set was evaluated exactly once after all decisions were frozen.
```
