# InferAI — Professor Review Response

Consolidated research evaluation addressing dataset transparency, lexical diversity, annotation agreement, held-out performance, calibration, leakage auditing, and explainability scope. **Core model architecture unchanged** (Sentence-BERT + logistic regression + hybrid rules).

## Executive summary

- Random holdout accuracy: **0.9079754601226994**
- Held-out test accuracy: **0.955**
- Macro F1 (random holdout): **0.8795819498451932**

Key takeaway: high in-distribution accuracy reflects template-heavy training data; held-out curated evaluation (~76% accuracy) exposes distribution shift. Reporting now includes length-aware lexical metrics, bootstrap κ, per-class held-out metrics, calibration diagnostics, and cross-split leakage checks.

## 9. Limitations

- **Synthetic skew:** Merged training data is dominated by template-generated Anumana examples after deduplication.
- **Small real-world corpus:** 200 curated training + 200 held-out test limits statistical power.
- **Simulated annotator 2:** κ is optimistic relative to fully independent human annotation.
- **Embedding SHAP:** Not token-faithful; hybrid rules not covered by SHAP.
- **Uncalibrated probabilities:** Confidence scores require cautious interpretation (see calibration report).
- **English-only short spans:** Nyāya taxonomy mapping is approximate for modern rhetorical text.

## 10. Future work

- Expand independently annotated real-world data; rebalance class priors.
- Token-level attributions and faithfulness user studies.
- Post-hoc probability calibration on validation fold.
- Cross-lingual and longer argumentative discourse support.
- Fine-tune or lightly adapt Sentence-BERT on in-domain Nyāya-labeled text.
